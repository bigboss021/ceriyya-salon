# 🌸 Ceriyya Salon & Beauty Klin

Website resmi untuk **Ceriyya Salon & Beauty Klin**, salon kecantikan modern dan elegan di Indramayu, Jawa Barat.

## ✨ Fitur Utama
- **Desain Luxury Rose Gold & Blush Pink**: Tampilan modern, feminin, dan elegan dengan animasi halus serta efek glassmorphism.
- **Katalog & Filter Treatment**: Daftar lengkap perawatan kecantikan:
  - *Lash & Brow Artistry* (Eyelash Extension Russian Volume, Korean Natural, Lash Lift & Tint, Brow Lamination)
  - *Face & Skin Treatment* (Korean Glass Skin, Detox Charcoal Facial, Acne Purifying)
  - *Spa & Body Wellness* (Ceriyya Signature Royal Body Spa, Hair Spa Creambath)
  - *Makeup Artistry* (Wisuda, Pesta, Lamaran / Prewedding)
- **Interactive Before & After Slider**: Perbandingan langsung hasil treatment bulu mata sebelum dan sesudah pengerjaan.
- **Sistem Reservasi Online & Integrasi WhatsApp**: Pilihan treatment dengan estimasi total harga otomatis (*real-time*), pemilihan tanggal & jam, serta pengiriman pesan reservasi rapi langsung ke WhatsApp Admin.
- **Paket Bundling Hemat**: Penawaran paket kombo perawatan favorit dengan harga spesial.
- **FAQ Interaktif**: Pertanyaan umum seputar reservasi, ketahanan lash, dan metode pembayaran.
- **Lokasi & Peta**: Terintegrasi dengan Google Maps di *Jln. Pasar Baru, Komplek Ruko Jangkar Mas Residen No. 5, Indramayu*.

## 🚀 Cara Menjalankan
Buka file `index.html` langsung di browser, atau jalankan menggunakan web server lokal:
```bash
# Menggunakan Python
python -m http.server 3000

# Atau menggunakan Node.js
npx serve .
```
Akses di browser melalui: `http://localhost:3000`
